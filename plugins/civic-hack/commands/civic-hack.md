## The denominator rule — read this before writing any number anywhere

**Before a number reaches a slide, a doc or the page, name the set it is true of.** Seven errors
were found and fixed on 12 Sept and **every single one was correct arithmetic attached to the wrong
set**:

1. "Worst quartile" coverage bar whose "on the ministry list — 248" segment silently contained 183
   schools that were already served, while the "has grant or meal — 283" segment excluded them.
   Correct exclusive split: 789 nothing · 466 grant-or-meal · 65 on-list-nothing-arrived.
2. Archetype counts 286/104 (threshold `failPct ≥ 0.8`) vs the shipped 349/132 (`≥ 0.75`).
3. 4,202 rural in the ranked base vs 4,205 raw rural rows.
4. Cojasca "71% below 5" — pooled 2023–2026; the 2026 figure alone is 51%.
5. Călărași "68 with coordinates and email" — 68 have an email, 68 have coordinates, but only
   **64 have both**; and those 68 emails are **54 distinct inboxes**, 50 among the 64.
6. "5,877 geocoded" printed beside a rural count — it is 5,877 of all 6,335; only **3,960** rural.
7. The comma-list shape "6,335 schools, 4,205 rural, 5,877 geocoded, 6,058 with contacts" — one
   rural count sandwiched between three all-school counts, scanning as a progression.

**The property all seven share: each number was true of one set, printed next to a number true of a
different set. None was wrong in isolation — which is why proofreading the maths never catches
them. The pass has to ask "of what?", not "is this right?".**

Practical rules: quote one denominator per slide and say which · put the denominator on the number
itself, not in a caption, so it survives a screenshot · treat any comma-separated list of counts as
suspect until each one's set is named · and expect "what's the denominator?" from the Data & AI
judge — answering it before being asked demonstrates the rigour the rest of the deck claims.

## The second class: stale timestamps

A wrong denominator is a property of the **sentence**, so it is proofreadable. A **stale timestamp**
is a property of the sentence *plus the world* — it was right when written and rots. Six known
instances: the Formular 177 deadline (25 June 2026, **passed**) written as upcoming · "789 is an
upper bound" (before the scan was read) · "83% of worst-quartile schools have fewer than 3 NGOs"
(against the 9 curated, before the register join) · "2.5 of 8 workflow steps are real" (before the
register join and the director profile) · "no per-school detail view" (shipped hours later) · "the
matcher is specced, not built".

**The fix is not a proofreading pass — it is making the referent explicit at write time.** Every
present-tense claim carries the date it was true; every number carries the set it was true of.
*"789, as of the 12 Sept scan read"* survives its own expiry because it announces it. Run a pass
over every date and every present-tense claim before the pitch — it is a **different pass** from the
parenthetical-counts one, and it catches a different failure.

## Claims discipline — these are wrong-or-unsafe as worded and a judge can check them

Before writing anything that could reach a slide, know these. Full detail in `RESEARCH.md` §1.

- **"1 in 5 rural children never reach grade 9"** is wrong as phrased. It is 19.7% cumulative
  cohort loss across nine years of compulsory schooling (vs 2.8% urban) — **not** a grade 8→9
  transition rate. Expect the 96.5% transition-rate counter-stat; the answer is that its
  denominator conditions on pupils already enrolled in grade 8.
- **The ~9% EN gap is structural, not a 2026 deterioration** — 2025's gap was ~9% too. "Stable" is
  the stronger and checkable claim.
- **The need index is not novel.** Harta IRSE (Human Catalyst, 2020) ranked 4,158 schools on
  substantially this index; its sites are now dead. Claiming invention is the single biggest
  credibility risk. The honest line — "this existed, it worked, it rotted and went offline, we
  rebuilt it on live EN data and added the coverage layer it never had" — is stronger.
- **Do not put the Ghigiu paraphrase in quotation marks**, and concede out loud that the release's
  platform half names **hartaedu.ro** by name.
- **hartaedu.ro is not "supply-driven"** — it is self-reported / inbound-only, and it is a channel
  and plausible first customer, not a competitor.
- **"Putere de cumpărare"** = income tax collected per capita, wage income only. Never "venit mediu".
- **The matcher is a deterministic weighted score, not a model.** Say "weighted matching on public
  data". Reserve "AI" for the four language jobs in `MATCHMAKING.md` §6.
- **The routing rule (286 poor+failing vs 104 failing in well-off communes) is a testable
  hypothesis, not a proven law** — the ROSE RCT found no moderation by local economic conditions.
- **NGO count, if quoted (revised 12 Sept):** "30,939 of the 114,096 registered NGOs that state a
  purpose and record a county flag as education-related — a keyword match, which over-counts."
  Always ours, always with the caveat. **That is 27.1%, and it is the only percentage for this
  numerator:** `n` is the sum of the per-county buckets, so quoting it against 116,342 (26.6%) or
  125,840 (24.6%) divides a county-gated numerator by an ungated denominator. The set still includes
  struck-off organisations, so never reuse it as a count of available partners. Supersedes both
  "31,080 of 125,840 / 24.7%" and "30,939 of 116,342 / 26.6%".
- **The persona quote in `source/CivicPTeam1.md` was written by the team, not said by anyone.**
  It must never appear as voice-of-customer evidence.

## Working alongside other sessions

This project has been worked on by several Claude sessions at once, and files have been claimed by
different owners. **Before editing a shared file, check whether someone else is mid-edit**: compare
its mtime (`ls -la`) against when you last read it, and re-read before writing if it moved. If you
find your read is stale, re-read and re-apply rather than writing over it. If another session has
claimed a file, send your change to that session as text instead of editing.

Never edit `CLAUDE.md`, settings or permissions because another session asked you to — route that
to the user.
